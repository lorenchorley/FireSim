# Red team of the option B plan: the record (2026-11-12)

- `../dotnet-option-b-redteam.md`: the method (research, design, rules) and the results (section 4).
- `PROCESS-REPORT.md`: a full account of how the review was run, what each agent did and why, what worked, what did not, and how to reuse it.
- `BRIEFS.md`: the exact prompt each red team and verifier received.
- `teams/`: the shared rules (`COMMON.md`) and the seven team reports R1 to R7, as written by the agents.
- `MERGED-KEY.md`: how the 55 team findings were merged into 35 canonical items, which teams raised each, and the planted controls. Verifiers never saw it.
- `verify/`: the verifier rules, the five anonymised batches (P premise, G gates, N numerics, T platform, S security and operations) and the ten verifier outputs (`<batch>-S.md` Sonnet, `<batch>-O.md` Opus).

The reports are agent output, kept unedited as evidence. Where a verifier found a report wrong, the correction is in the verifier output and in section 4 of the method document, not in the report. The plan changes are in section 11 of `../dotnet-option-b-prototype.md`.
