# M0 spikes

The six spikes of milestone M0 in [`../air-slice-wind-detail-honest-speed.md`](../air-slice-wind-detail-honest-speed.md) (section 10). Each folder holds a note with the question, the method, the numbers, the limits and how to reproduce. The throwaway prototypes are kept as `prototype.patch` and are **not reviewed code**. The measuring harnesses that run in node are in [`tests/spikes/`](../../../tests/spikes/), skipped unless `FIRESIM_SPIKE=1` is set, so `npm test` never runs them. Done 2026-10-13 against the contracts commit `ca8e637`.

## What the spikes did not do

- Nothing was seen on a phone. S4 and S5 are 412 x 915 desktop screenshots from software rendering; S3 extrapolates to the phone from one data point (the factor 2.35 from the 3-D air step); S1 forced the signal levels because the real pace tracker does not exist yet.
- S6 is inconclusive as well as negative: an expert re-label of the 80 tiles is the cheapest way to make it conclusive.
- Open in the notes: S4's one unexplained frame (86 of 377,000 pixels differ from an unpatched HEAD in Realistic, cause not found) and S5's last-minute `light=n10s-min` variant (not evaluated).
