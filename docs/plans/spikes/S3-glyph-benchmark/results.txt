== 12 extrapolation
3-D air step of a standard 6 km engine: at the start median 16.80 ms (min 15.33), at the end median 16.60 ms (min 15.09); the brief quotes 17.5 ms for this machine and 41.1 ms for the phone.
Factor used: 2.35; with this run's medians it would be 2.45 (start) and 2.48 (end). Load average now: 0.95 3.14 6.46
phone factor 2.35 = 41.1 ms (phone) / 17.5 ms (this machine) for the 3-D air step: ONE data point, and the code differs (stencil and multigrid, not a branchy sampler).
4x throttle = 4 x this machine's time. Budgets: 8 ms on the phone (plan 9.8), 32 ms at the throttle. Margin: a phone estimate of at most budget / 1.5 = 5.3 ms.
The machine is shared and its timings carry interference, which inflates them. The classes take that into account:
"fits with margin" / "fits": even the p95 of this loaded run x 2.35 is within 5.3 / 8 ms, so a quiet machine can only do better (safe).
"over (needs Nx)": even the FASTEST rebuild x 2.35 exceeds 8 ms; N is the speed-up that a quiet machine would need over that rebuild to fit (the claim is only as good as the load estimate).
"undecided": the fastest rebuild fits but the loaded p95 does not.
The same rules at the 4x throttle use 4 x the time here against 32 ms, so the last column is the question "is the time here within 8 ms": the throttle budget is 1.70x looser than the phone budget.
